- Content routes define their own metadata, using pageHead for simple private pages; why: each view needs its own title and description rather than inheriting generic root metadata.
- Bulk v2 document extraction uses an on-demand browser helper and passes extracted text to the existing authenticated generation pipeline; why: PDF/DOCX parsers must not enter SSR execution or bypass billing and job tracking.
