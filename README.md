# FlashPilot

Novo projeto. Eu quero um programa que permite fazer flashcards para a memorização de conteúdo de estudo. Então, cada flashcard teria uma pergunta e ao virar o flashcard, a sua respectiva resposta. É preciso permitir que as perguntas e também as respostas sejam ditadas pelo microfone ou escritas pelo teclado. É preciso dividir os flashcards por matérias, matérias que eu vou cadastrar também ditando por microfone ou por teclado. Portanto, teremos um banco de dados onde eu vou salvar as categorias de matérias e os respectivos flashcards divididos por assuntos. Portanto, dentro de cada matéria eu terei subdivisões de assuntos. É preciso ainda ter algum serviço de inteligência artificial que calcule o momento da revisão de cada assunto, de modo que eu vá recebendo as notificações para que revise determinado assunto de acordo com a média de memorização do cérebro de uma pessoa comum. Verifique as informações e faça o projeto.
